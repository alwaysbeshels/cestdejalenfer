La [caption](caption.txt) contient le français puis l'anglais dans un seul texte court. Les [textes alternatifs](textes-alternatifs.md) sont séparés par image.

Les pages utilisent les données locales déjà disponibles. Aucun générateur ni collecte externe de nids-de-poule ou de colmatage n'a été exécuté. Les périodes, dénominateurs et limites affichés par le site sont conservés; les positions et signalements ne sont pas présentés comme un inventaire exhaustif de trous physiques.

Les captures longues montrent tout le contenu défilant de chaque vue; les tableaux à défilement interne conservent leurs propres limites. Utiliser les JPEG carrés pour Instagram. La [provenance](../_sources/current/provenance.json) conserve les contrôles et la sélection d'arrondissement.
